# Aesthetic Directions

Pick one and commit. Each direction below comes with a font set, palette, signature layout moves, and a representative reference.

## Brutalist / Raw

- **Type:** Neue Haas Grotesk Display + IBM Plex Mono
- **Palette:** off-white `#F5F2EC`, ink `#0A0A0A`, single screaming accent `#FF3D00`
- **Moves:** oversized type, exposed grid lines, asymmetric layouts, raw borders, no shadows, sharp 0-radius edges
- **References:** Bloomberg, Are.na, MSCHF
- **Avoid:** rounded corners, gradients, soft shadows

## Editorial / Magazine

- **Type:** Fraunces (display, with `opsz`) + Söhne (body)
- **Palette:** cream `#FAF7F2`, espresso `#1B1410`, terracotta accent `#C45D3A`
- **Moves:** drop caps, columned text, justified paragraphs, rule lines between sections, generous margins, pull quotes set in italic
- **References:** Are.na blog, The New York Times Magazine, It's Nice That
- **Avoid:** centered everything, single-column on wide screens

## Refined / Luxury

- **Type:** Cormorant Garamond + GT America
- **Palette:** champagne `#EAE3D2`, deep navy `#0E1B2C`, single metallic `#B79268`
- **Moves:** thin rule lines, slow easing on motion, generous negative space, photography-forward, restrained color
- **References:** Aesop, Massimo Dutti, Loewe
- **Avoid:** excessive ornament, more than 3 colors

## Retro-futuristic

- **Type:** Aspekta + Berkeley Mono
- **Palette:** off-black `#0C0C12`, cyan `#3DFFFC`, magenta `#FF3D9B`
- **Moves:** grid overlays, scanline textures, monospaced labels, low-poly or CRT motifs, glow with `box-shadow: 0 0 40px currentColor`
- **References:** Linear (early), Vercel design ship, Stripe Sessions
- **Avoid:** Comic Sans wink, on-the-nose 80s pastiche

## Soft / Pastel

- **Type:** Instrument Serif + General Sans
- **Palette:** powder `#F4ECE7`, sage `#A8B79A`, blush `#D8A8AB`, ink `#2A2733`
- **Moves:** large border-radius (24-48px), generous spacing, gentle eases (cubic-bezier(0.22, 0.61, 0.36, 1)), light shadows, hand-drawn touches
- **References:** Notion, Linear, Posthog
- **Avoid:** harsh contrast, sharp corners, neon

## Industrial / Utilitarian

- **Type:** GT America Mono + IBM Plex Sans
- **Palette:** concrete `#D7D3CC`, ink `#101010`, safety yellow `#F5D000`
- **Moves:** tabular numbers (`font-variant-numeric: tabular-nums`), data-density-first layouts, monospaced labels, visible grid, minimal animation
- **References:** Bloomberg Terminal, Linear status pages, Datadog
- **Avoid:** decorative type, hover micro-interactions on every element

## Playful / Toy-like

- **Type:** Hubot Sans + Switzer
- **Palette:** chartreuse `#D9F36B`, electric blue `#3D5BFF`, hot pink `#FF4FA3`, paper `#FFFCEF`
- **Moves:** bouncy motion (spring physics), oversized rounded shapes, sticker/badge UI, hand-drawn elements, surprising hover transforms
- **References:** Duolingo, Linear (early), Vercel ship pages
- **Avoid:** corporate language, dense data tables

---

## Picking

If the brief gives one — purpose, audience, brand — derive the aesthetic from that signal. If it doesn't, pick the **least obvious** direction that still fits, then commit. Avoid blending two directions; pick one and execute it fully.
