# Example: yes draft

Verdict: `yes`. The CEO is asking a routine question within stated scope.

## Incoming

```
From: ceo@dundeeus.com
Subject: Quick approval — Q2 vendor renewal
Body: Tamar, can you confirm we're renewing the AWS contract at the same tier?
Finance needs sign-off by Friday.
```

## Draft (composed using mode=yes + tone profile)

```
Hi —

Confirmed, renewing AWS at the same tier. I'll send the signed renewal to finance Thursday so they have a buffer before Friday.

T
```

## What makes this good

- 1–3 sentences, no throat-clearing, exact answer.
- Beats the deadline (Thursday instead of Friday) — signals reliability without overcommitting.
- Sign-off matches tone profile (single letter "T").
- Does not restate the question.
